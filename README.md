# Reproducibility Code for Simulation and Real-Data Analyses

This repository contains the R programs and saved numerical results used to produce the simulation tables, figures, and TCGA-BRCA real-data analysis in the accompanying manuscript and Web Appendix. The simulation programs evaluate weighted estimating-equation (WEE), internal control-variate (ICV), uncertainty-adjusted ICV (UICV), and adaptive control-variate (ACV) estimators for a right-censored additive-risk mixture-cure model.

## Scenario and setting labels

- `S1`, `S2`, and `S3` in `addICV.R` correspond to `pai1`, `pai2`, and `pai3`, respectively.
- `T1`, `T2`, `T3`, `T4`, and `T5` in `addACV.R` correspond to `tau1`, `tau2`, `tau3`, `tau4`, and `tau5`, respectively.
- `L` and `H` identify the two censoring and cure-rate configurations used in the simulations.
- `n300` and `n600` denote internal sample sizes of 300 and 600.

## File descriptions

### Simulation programs

- `addICV.R` runs the WEE and ICV simulations. Setting `S1` generates the Scenario 1 results, while settings `S2` and `S3` generate the Scenario 2 results. The ICV estimators use one, two, or four auxiliary time points.
- `addACV.R` runs the WEE, ICV, and ACV simulations. Setting `T1` generates the Scenario 3 results, and settings `T2`-`T5` generate the Scenario 4 results.
- `uncertainty.R` compares the original ICV estimator, which treats the external Kaplan-Meier estimates as fixed, with the uncertainty-adjusted ICV estimator. It evaluates several external-to-internal sample-size ratios and produces raw results, summary tables, and SE/SD calibration plots.

The directories `scenario1/`, `scenario2/`, `scenario3/`, `scenario4/`, and `uncertainty/` contain the saved replication-level and summary results used for the manuscript tables. The `uncertainty/` directory also contains the auxiliary-time grids and SE/SD calibration plots.

### Real-data files

- `realdata/GetData.R` downloads the TCGA-BRCA clinical and BCR Biotab data through the `TCGAbiolinks` package, extracts estrogen-receptor status, applies the analysis inclusion criteria, and saves the processed dataset as `realdata/sdata.TCGA.RData`.
- `realdata/sdata.TCGA.RData` contains the processed TCGA-BRCA survival, age, and estrogen-receptor-status data used by the analysis. This file is included so that the main analysis can be reproduced without downloading the source data again.
- `realdata/realdata.R` performs the analysis reported in Table 5 and creates the Kaplan-Meier plot reported in Web Figure S3. Run this script from the `realdata/` directory. It writes the numerical results to `result.txt` and saves the Kaplan-Meier plot as `kmplot.pdf` and `kmplot.eps`.

### Plotting programs

- `boxplot.R` reads the replication-level `S1-L-n300` Scenario 1 results and produces Figure 1, which displays boxplots of the WEE and ICV estimates under a moderate cure rate and `n = 300`. The figure is saved in PDF and EPS formats in the project root.
- `bandwidth.R` performs the bandwidth study for Scenario 1 with `n = 300` under moderate and high cure rates. It creates `MSEplot_S1_moderate_cure_n300.pdf`/`.eps` and `MSEplot_S1_high_cure_n300.pdf`/`.eps`, corresponding to Web Figures S1 and S2.

## Software requirements

The analyses require R and the following R packages:

```r
install.packages(c(
  "survival", "MASS", "lars", "iterators", "foreach",
  "ggplot2", "miscTools", "gridExtra", "survminer",
  "mvtnorm", "Matrix", "glmnet", "dplyr"
))
```

`GetData.R` additionally requires the Bioconductor package `TCGAbiolinks`:

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}
BiocManager::install("TCGAbiolinks")
```

The MPI simulations require the `Rmpi` and `doMPI` packages together with a working MPI implementation. Installation of `Rmpi` is system dependent and normally requires access to the MPI libraries and headers on the computing cluster.

## Parallel computation

`addICV.R`, `addACV.R`, and `bandwidth.R` use MPI-based parallel computation through `foreach`, `Rmpi`, and `doMPI`. By default, `uncertainty.R` also uses MPI, but it can be run sequentially by setting `PARALLEL_BACKEND=serial`. The data-acquisition, real-data, and boxplot scripts do not require MPI.

For local parallel computation, the MPI backend can be replaced by `doParallel` while retaining the existing `foreach` workflow:

```r
library(doParallel)

n_workers <- max(1L, parallel::detectCores() - 1L)
cl <- parallel::makeCluster(n_workers)
doParallel::registerDoParallel(cl)

# Keep the existing foreach(...) %dopar% { ... } computation here.

parallel::stopCluster(cl)
```

The number of workers should be adjusted according to the available CPU cores and memory.

## Running the analyses

Run the simulation scripts from the project root. The scripts use environment variables to select the setting, replication range, output directory, and parallel random-number seed. The examples below use a POSIX shell; use the equivalent environment-variable syntax on other systems.

### Scenario 1

The following example runs `pai1` (`S1`) under the `L` configuration with `n = 300` and saves the results in the same layout as the included Scenario 1 results:

```bash
SETTING_ID=S1-L-n300 \
OUTPUT_DIR=scenario1/L-n300 \
REP_START=1 REP_END=500 \
mpirun Rscript addICV.R
```

The Scenario 1 settings are `S1-L-n300`, `S1-H-n300`, `S1-L-n600`, and `S1-H-n600`.

### Scenario 2

Use `S2` for `pai2` and `S3` for `pai3`. For example:

```bash
# pai2: Table S1
SETTING_ID=S2-L-n300 \
OUTPUT_DIR=scenario2/pai2/L-n300 \
REP_START=1 REP_END=500 \
mpirun Rscript addICV.R

# pai3: Table S2
SETTING_ID=S3-L-n300 \
OUTPUT_DIR=scenario2/pai3/L-n300 \
REP_START=1 REP_END=500 \
mpirun Rscript addICV.R
```

Each incidence setting can be combined with `L` or `H` and `n300` or `n600`.

### Scenario 3

Scenario 3 uses `T1` (`tau1`):

```bash
SETTING_ID=T1-L-n300 \
OUTPUT_DIR=scenario3/T1-L-n300 \
REP_START=1 REP_END=500 \
mpirun Rscript addACV.R
```

The included Scenario 3 results contain the `L` and `H` configurations for `n = 300` and `n = 600`.

### Scenario 4

Scenario 4 uses `T2`-`T5` (`tau2`-`tau5`). For example:

```bash
SETTING_ID=T2-L-n300 \
OUTPUT_DIR=scenario4/T2-L-n300 \
REP_START=1 REP_END=500 \
mpirun Rscript addACV.R
```

Replace `T2` with `T3`, `T4`, or `T5` to reproduce the other Scenario 4 settings.

### Uncertainty analysis

For example:

```bash
SETTING_ID=S1-L-n300 \
OUTPUT_DIR=uncertainty/L-n300 \
REP_START=1 REP_END=500 \
PARALLEL_BACKEND=mpi \
mpirun Rscript uncertainty.R
```

The script supports `S1-L-n300`, `S1-H-n300`, `S1-L-n600`, and `S1-H-n600`. The saved results included here are for `S1-L-n300` and `S1-L-n600`.

### Real-data analysis

The processed dataset is already included. To reproduce Table 5 and Web Figure S3, run:

```bash
cd realdata
Rscript realdata.R
cd ..
```

To download and rebuild the processed dataset from the source data before running the analysis:

```bash
cd realdata
Rscript GetData.R
Rscript realdata.R
cd ..
```

Running `GetData.R` requires an internet connection and access to the GDC data service.

### Figures 1, S1, and S2

```bash
# Figure 1
Rscript boxplot.R

# Web Figures S1 and S2 (MPI)
mpirun Rscript bandwidth.R
```

Full simulation runs are computationally intensive. Reduce the replication range and number of workers when performing preliminary checks.
